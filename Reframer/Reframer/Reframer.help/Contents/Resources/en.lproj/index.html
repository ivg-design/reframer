Product boundaries

  • Local WebM, MP4/M4V/MOV, AVI, DV, MPEG/transport-stream, and 3GP/3G2 media
  • Explicit, consent-gated YouTube playback after a Made for Kids preflight
  • AVFoundation playback and Core Image filters
  • One video-and-controls window for macOS and window managers
  • One 48-point control row at 920 points and wider; two rows through the 640-point minimum with no hidden controls
  • Local-media whole-overlay lock requires a registered global recovery chord
  • YouTube stays unlocked so required player controls remain interactive
  • Native bundled Help that never fetches network content
  • Network access only for the explicit YouTube workflow; no analytics, updater, or downloaded native executable components; authorized YouTube playback loads remote web content and IFrame API JavaScript in WebKit
