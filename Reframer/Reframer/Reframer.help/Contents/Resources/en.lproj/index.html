Product boundaries

  • Local MP4, M4V, and MOV files
  • AVFoundation playback and Core Image filters
  • One video-and-controls window for macOS and window managers
  • One 48-point control row at 920 points and wider; two rows through the 640-point minimum with no hidden controls
  • Whole-overlay lock requires a registered global recovery chord
  • Native bundled Help with no streaming, analytics, network entitlement, or downloaded components
